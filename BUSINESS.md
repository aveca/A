# Vision Agent — Business Model

## Proposition de valeur

Vision Agent transforme n'importe quelle caméra en système de vision par ordinateur intelligent, 100 % local, sans dépendance cloud, sans abonnement obligatoire.

**Promesse :** un seul bouton pour détecter, enregistrer, comprendre et apprendre.

---

## Segments de clients

| Segment | Besoin principal | Prix cible |
|---|---|---|
| Petits commerçants | Caisse auto, inventaire rapide | Starter / Pro 49€/mo |
| PME industrielles | Contrôle qualité, comptage | Pro 49€/mo / Enterprise |
| Logistique & entrepôts | Scan codes-barres, tracking | Pro / Enterprise |
| Smart home / sécurité | Surveillance, détection d'intrusion | Pro |
| Développeurs & intégrateurs | API et personnalisation | Enterprise |

---

## Modèles de revenus

1. **Freemium**
   - Starter gratuit pour l'adoption
   - Limites : 1 caméra, export JSON, pas de cloud

2. **Abonnement Pro** — 49€/mo (ou 490€/an)
   - Caméras illimitées
   - Rapports automatiques
   - Support email

3. **Licence Enterprise** — sur devis
   - Multi-site
   - API dédiée
   - Support téléphonique
   - Personnalisation

4. **Revenus complémentaires**
   - Prestation d'intégration : 1 500€ - 10 000€
   - Formation : 500€/journée
   - Cloud storage premium

---

## KPIs cibles

- 1 000 téléchargements Starter (mois 1)
- 5 % de conversion Pro
- 50 licences Enterprise (année 1)
- MRR cible : 10 000€/mois à 12 mois

## Canaux de distribution

- Site web avec landing page

## Stack de monétisation
